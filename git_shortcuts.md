# Git Shortcuts (from ~/.gitconfig aliases)

- `git b`: branch
- `git a`: add .
- `git gr`: log --graph --oneline --all
- `git fo`: fetch origin
- `git s`: status
- `git bh`: branch
- `git co`: checkout
- `git cbc`: checkout
- `git c`: checkout
- `git cm`: commit -m
- `git p`: push
- `git f`: fetch
- `git o`: origin
- `git cl`: clean -df
- `git pl`: pull
- `git ps`: push
